# AG Premium Domicile

Pack **Premium** pour le thème gratuit **AG Starter Domicile** (services à la personne / aide à domicile).

C'est un **plugin** : il n'ajoute que du **design** par-dessus le thème, activé quand la licence est *premium* (ou via le **mode test** dans Personnaliser → AG Premium Domicile).

## Ce qu'il apporte
- Typographie premium : **Fraunces** (titres) + **Nunito Sans** (texte)
- **Bandeau de confiance** sur le hero : Agréé SAP · Crédit d'impôt 50 % · 7j/7 (éditable)
- Boutons dégradés, cartes adoucies avec ombres et survol animé
- **Témoignages animés** (mise en avant qui tourne)
- **Header collant** raffiné + **bouton « Devis gratuit » flottant**
- Bande CTA en dégradé vert/or

## Installation
1. Installer et activer le thème **AG Starter Domicile** (gratuit).
2. Installer ce plugin (Extensions → Ajouter → Téléverser), puis l'activer.
3. La licence Premium l'active automatiquement. Pour prévisualiser sans licence : Personnaliser → **AG Premium Domicile** → cocher *Mode test*.
